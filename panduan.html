PUSAT PENGELOLAAN

Panduan Mudah Mengolah Website

Petunjuk praktis bagi Kepala Sekolah, Dewan Guru, dan Operator SDN Inpres Arso VIII untuk memperbarui berita, foto, dan data sekolah tanpa kesulitan teknis.

Mudah Diakses & Mandiri

1. Cara Membuka Website di Komputer / Laptop Sekolah

Website ini dirancang menggunakan standar HTML5, CSS3, dan JavaScript murni sehingga:

  • Dapat langsung dibuka di browser: Buka folder WEBSITE-SEKOLAH-SDN INPRES ARSO VIII, lalu klik dua kali pada file index.html. Website akan langsung terbuka sempurna di Google Chrome, Microsoft Edge, atau Mozilla Firefox!
  • Dapat diakses Offline maupun Online: Website tetap berjalan dan berpenampilan rapi meskipun jaringan internet sedang tidak aktif atau lambat.
  • Bisa disimpan di Flashdisk: Cukup salin seluruh isi folder ini ke flashdisk, dan website siap dipresentasikan di komputer mana pun tanpa instalasi aplikasi server tambahan (seperti XAMPP atau Python).

Langkah Praktis

3. Cara Mengubah Teks atau Foto Guru (Cukup dengan Notepad)

  1. Buka File dengan Notepad atau VS Code:
    Klik kanan pada file yang ingin diubah (misalnya guru.html) lalu pilih Open With > Notepad.
  2. Cari Teks yang Ingin Diubah:
    Tekan tombol Ctrl + F pada keyboard, lalu ketik nama guru atau angka yang ingin diubah.
  3. Ganti Teksnya:
    Ubah teks sesuai data terbaru (misalnya jika ada penambahan guru baru atau pergantian wali kelas).
  4. Simpan Perubahan:
    Tekan Ctrl + S untuk menyimpan. Kemudian buka kembali file tersebut di browser (atau tekan F5 / Refresh), dan perubahan langsung muncul seketika!
  5. Mengganti Foto:
    Letakkan file foto baru di dalam folder images/ (misal: images/kepala-sekolah.jpg), lalu pada file HTML ubah bagian src="images/kepala-sekolah.jpg".

Siap Presentasi

5. Bahan Panduan Pemaparan ke Kepala Sekolah & Dewan Guru

Gunakan poin-poin presentasi berikut saat memaparkan website ini di depan Kepala Sekolah (Bapak Adi Puspito, S.Pd), Dewan Guru, dan Komite Sekolah agar manfaatnya langsung dipahami secara jelas:

1. Mendukung Akreditasi A & Profil Resmi

Website ini memuat data pokok, SK Izin Operasional PTSP, SK Akreditasi A BAN-SM, luas lahan 10.000 m², dan 31 inventaris sarpras secara transparan untuk penilaian instansi kedinasan.

2. Publikasi Akses Starlink & Literasi Digital

Membuktikan kepada dinas dan masyarakat bahwa sekolah di Kampung Dukwia, Keerom aktif memanfaatkan internet satelit Starlink untuk kemajuan pembelajaran siswa.

3. Pusat Informasi Orang Tua Murid dari HP

Orang tua siswa dapat mengecek jadwal seragam 5 minggu, jam belajar per jenjang kelas, aturan 5S, larangan sekolah, dan jadwal kurve Jumat Bersih langsung lewat ponsel tanpa perlu datang ke sekolah.

4. Sistem Pendaftaran Siswa Baru (PPDB) Online

Wali murid baru bisa mendaftar secara online dari HP, dan data pendaftar langsung tersimpan rapi di Login Admin untuk diverifikasi operator sekolah.

5. 100% Bebas Biaya Server & Bebas Kadaluarsa

Website ini berjalan di infrastruktur awan Netlify kelas dunia secara gratis selamanya. Sekolah tidak terbebani biaya langganan hosting bulanan sepeser pun.

6. Kesiapan Upgrade ke Domain Resmi (.sch.id)

Draf surat permohonan ke PANDI sudah siap dicetak. Kapan pun sekolah ingin menaikkan ke domain sdninpresarso8.sch.id (biaya ~Rp 55.000/tahun dari BOS), sistem langsung terhubung dalam 1 hari.
